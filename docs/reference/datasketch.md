# `pyroid.datasketch`

An exact drop-in for datasketch 2.0.0's MinHash family: `MinHash`, `LeanMinHash`, `MinHashLSH`,
`MinHashLSHForest` and `MinHashLSHEnsemble`. Guide: [`pyroid.datasketch`](../guides/datasketch.md).
